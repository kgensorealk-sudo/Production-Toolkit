# Phase 1 second-review fixes

The review task is constructed once from task instructions and the prompt. The same canonical question drives local batch planning, the server request, retrieval enforcement and continuation. A fresh review replaces prior canonical instructions rather than nesting them. Continuation keeps its stored question and separately validates unchanged instructions.

Inventories below 2.8 MB retain the existing request format. Larger inventories send all record IDs, kinds, source identity, diagnostic/binding metadata and original record lengths, plus full text for the selected batch or specifically requested query IDs and their associated PDF records. Other record text is explicitly marked unavailable. Stable original ordering preserves global E references; original lengths preserve batch boundaries and cursor keys. Full OPT counts, flagged counts and whitespace-only counts remain available from local inventory metadata. The server validates omission markers and rejects attempts to retrieve/search unavailable text.

Counts-only requests can send metadata without record text. An oversized unscoped request asks the user for a supported whole-query/OPT review or specific query IDs. Oversized selected text/metadata is rejected explicitly before a cloud request; the 4 MB API ceiling remains. This is bounded transport, not unlimited file support or silent truncation. The full evidence and manuscript remain in the local workspace, and saved viewers resolve against the original hashes.

Evidence retrieval budgets now measure serialized UTF-8 bytes. Slices shrink to fit while exposing a strictly advancing nextTextOffset. If metadata alone cannot fit, the tool returns an explicit error instead of an empty successful page with the same cursor. This also applies to the compact query-response tool. Existing model-round/tool-call limits remain; exceptionally long records can still exceed one model request's retrieval budget, which must remain disclosed rather than reported complete.

No manuscript fixtures or personal keys are used.
